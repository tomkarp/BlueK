BlueK offline
=============

Getting started
---------------
1. Extract the ZIP onto your computer (do not open inside the ZIP viewer).
2. Open BlueK.html in a recent desktop browser.

The HTML file contains the whole app. No installation, server, Node.js or
Python is needed. It can also be distributed on its own.

Features
--------
Create projects, open templates, edit/format/check/run Kotlin, use BluePlay,
import JSON or BlueJ projects, export JSON and export standalone HTML programs.
BlueJ ZIP export is not implemented.

Short links need the online share service and are hidden offline. Copy Full
Project Link encodes the project and targets https://bluek.de/; opening that
link requires internet.

Save your projects
------------------
Browser autosave depends on the browser and the location of BlueK.html.
Moving the file, clearing browser data or private browsing can remove access
to drafts. Use Save / Export > Export Project JSON for backups or submissions.
Reopen the .bluek.json file through Open / Import.

Before relying on offline use
-----------------------------
The offline version has not yet been widely tested in practice. Test it with
your own projects and browser before relying on it. Automated local-file
checks cover Chromium and WebKit; they are not a guarantee for every browser.

Use “Report a problem…” in BlueK to report bugs or missing Kotlin support.
Sending requires internet.
You can review the included data and choose whether to attach the project.
